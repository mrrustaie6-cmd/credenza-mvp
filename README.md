# Credenza — Portable Financial Identity

A consent-based trust engine that turns a migrant's real financial history —
payment behaviour, credit conduct, verifiable transactions — into a portable
profile that banks and fintechs in a new country can act on.

This repository contains an early concept demo, prepared alongside the
written business plan for the Estonia Startup Visa application.

## Live demo

Open `index.html` directly, or enable **GitHub Pages** for this repo
(Settings → Pages → Deploy from branch → `main` / root) to get a public link
you can attach to the Startup Committee application.

## What's in the demo

- An interactive "trust profile builder" — toggle data sources (verified
  documents, on-chain transaction history, social guarantor network, home-
  country registry) and watch a sample trust index assemble.
- A walkthrough of the four-step process: consent → verify → score → issue.
- A corridor map showing rollout status: Iran (pilot / live), Russia
  (building), Cuba and Venezuela (planned).

No real user data is collected anywhere in this demo — every score shown is
illustrative.

## Status

Concept stage. Business plan, market sizing, and compliance architecture are
documented separately. This demo exists to give the Startup Committee (and
any pilot bank partner) something concrete to click through, ahead of a
working MVP.
